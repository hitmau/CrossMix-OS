CrossMix Desktop v0.1.0 — TrimUI Smart Pro / CrossMix-OS

INSTALACAO PELO DINGUX COMMANDER

1. Extraia a pasta CrossMix-Desktop-Installer em qualquer lugar do cartao SD do CrossMix.
2. No console, abra Apps > File Manager (Dingux Commander).
3. Navegue ate CrossMix-Desktop-Installer/install.sh.
4. Selecione o arquivo e escolha Execute.
5. Volte para Apps. O aplicativo aparece como Desktop. Se a lista nao atualizar, reinicie somente a interface principal.

O instalador copia os arquivos do app para Apps/Desktop e os exemplos iniciais para Data/Desktop/Workspace. Exemplos e projetos que ja existirem no workspace nao sao substituidos. O instalador nao altera o boot nem o firmware.

PRE-REQUISITOS

- Cartao SD com CrossMix-OS montado no TrimUI em /mnt/SDCARD.
- Execute o script a partir da pasta CrossMix-Desktop-Installer extraida; nao mova o install.sh para fora da pasta payload.

O Dingux Commander permite executar arquivos pelo comando A (View or execute). Se o seu build mostrar o conteudo do script em vez de executa-lo, escolha Execute no menu do arquivo.

Se a instalacao falhar, confira se o ZIP foi extraido por completo e se a pasta payload continua ao lado do install.sh.
